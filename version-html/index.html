Restricciones
Los coeficientes pueden ser positivos, negativos o decimales. Se asume que todas las variables son no negativas (xᵢ ≥ 0). Se admiten restricciones ≤, ≥ e =.

Listo para optimizar

03 · Cómo funciona

Proceso de resolución implementado en JavaScript.

1. Convierte las restricciones en ecuaciones con variables de holgura, exceso y artificiales, según corresponda.

2. Aplica la fase I cuando se necesitan variables artificiales para obtener una base inicial factible.

3. Ejecuta pivotes simplex y registra cada tabla hasta hallar el óptimo o diagnosticar inviabilidad o no acotación.
